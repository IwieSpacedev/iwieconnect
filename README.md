# IwieConnect - Sitio Web de Internet Satelital

Este proyecto es un sitio web para un servicio de Internet Satelital / WiFi Satelital, desarrollado con React y Vite.

## Características

- Página principal con información sobre el servicio de Internet Satelital
- Página de contacto con formulario
- Botón flotante de WhatsApp en todas las páginas
- Diseño responsivo para dispositivos móviles y de escritorio

## Tecnologías utilizadas

- React
- React Router
- React Icons
- CSS puro para los estilos
- Vite como bundler

## Instrucciones de instalación

1. Clona este repositorio
2. Instala las dependencias con `npm install`
3. Ejecuta el servidor de desarrollo con `npm run dev`
4. Abre [http://localhost:5173](http://localhost:5173) en tu navegador

## Estructura del proyecto

- `/src/components`: Componentes reutilizables (Navbar, Footer, WhatsAppButton)
- `/src/pages`: Páginas principales (Home, Contact, Planes)
- `/src/styles`: Archivos CSS para componentes y páginas
- `/src/assets`: Imágenes y otros recursos

## Construcción para producción

Para construir el proyecto para producción, ejecuta:

```bash
npm run build
```

Los archivos generados estarán en la carpeta `/dist`.
